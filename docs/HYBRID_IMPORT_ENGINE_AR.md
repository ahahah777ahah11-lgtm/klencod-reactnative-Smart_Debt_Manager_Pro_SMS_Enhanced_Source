# محرك الاستيراد الهجين الذكي – التنفيذ الحالي

## ما تم تنفيذه في هذا الإصدار

- استبدال فحص SQLite النصي/التخميني بمسار Android أصلي يفتح نسخة مؤقتة من الملف بوضع القراءة فقط.
- فحص `sqlite_master` لاكتشاف الجداول.
- قراءة `PRAGMA table_info` للأعمدة والأنواع والمفاتيح الأساسية والقيود الافتراضية.
- قراءة `PRAGMA foreign_key_list` للعلاقات الخارجية.
- قراءة `PRAGMA index_list` و`PRAGMA index_info` للفهرسة وأعمدتها.
- قراءة الصفوف بحدود حماية (10,000 صف لكل جدول و50,000 صف إجمالًا)، مع وسم النتيجة بأنها مبتورة إذا بلغ الحد.
- تنفيذ `PRAGMA quick_check` و`PRAGMA foreign_key_check`.
- إنشاء SHA-256 لمصدر قاعدة البيانات، واستخدامه مع اسم الجدول ومعرف الحركة لمنع ترحيل الحركة نفسها مرة أخرى.
- مطابقة أسماء الجداول والأعمدة باستخدام قاموس مرادفات عربي/إنجليزي، مع استخدام المفاتيح الخارجية لاكتشاف عمود ربط العميل.
- حساب الدين والمدفوعات من الحركات ذات الاتجاه المعروف فقط. الحركة الغامضة لا تتحول إلى دين أو دفعة بالتخمين، بل تظهر كتحذير ولا تُرحّل.
- إبقاء دعم قاعدة Market DB القديمة عبر Adapter متخصص، بدل فقدان قواعدها المحاسبية.
- عرض تقرير schema والمطابقات للمستخدم، وطلب موافقته قبل الاستيراد.
- إيقاف الاستيراد إذا كانت قراءة الملف مبتورة، أو فشل فحص سلامة SQLite، أو ظهرت مخالفات مفاتيح خارجية.
- الحفاظ على الحركات التفصيلية ومعرفاتها الأصلية داخل المرجع والملاحظات عند ترحيلها.

## حدود النسخة الحالية

- لا يوجد استدعاء لنموذج ذكاء اصطناعي خارجي في هذا الإصدار؛ الاقتراحات الحالية حتمية مبنية على أسماء الحقول والأنواع والعلاقات. لا يرسل التطبيق بيانات العملاء إلى خدمة AI.
- لا تزال قاعدة التطبيق الحالية في واجهة WebView تستخدم طبقة التخزين المحلية الحالية؛ لم يتم ترحيل كامل نموذج العملاء والحركات إلى Room في هذا التحديث.
- مطابقة الحقول العامة تلقائية بالقرائن مع شاشة مراجعة/موافقة قبل الاستيراد؛ واجهة تحرير يدوي كامل لكل عمود ليست مكتملة بعد.
- بعض قواعد البيانات غير الموثقة قد تحتاج Adapter مخصصًا، خصوصًا إذا كانت دلالة الحقول المالية لا يمكن إثباتها من المخطط والقيم.
- ملفات Excel وPDF لها مسارات استيراد مستقلة؛ لا يعني نجاح فحص SQLite أن OCR أو جميع تنسيقات Excel تم التحقق منها.

## اختبارات JavaScript

تشغيل:

```bash
node run_tests.js
```

تتضمن مجموعة الاختبارات 21 حالة، بينها اختبار Schema-driven SQLite عام يثبت ربط عميل بحركتي دين/دفع وحساب رصيد 700، واختبار منع تكرار الحركات المستوردة.

## بناء APK

يتطلب البناء Android SDK واتصالًا لتنزيل Gradle والتبعيات عند عدم وجودها في ذاكرة Gradle المحلية:

```bash
./gradlew --no-daemon clean :app:assembleDebug
```

تم تضمين GitHub Actions في `.github/workflows/android-build.yml` لتشغيل الاختبارات وبناء APK ورفعه كـ Artifact.
