# مدير الديون الذكي برو SMS (Smart Debt Manager Pro SMS)

تطبيق محاسبي احترافي متكامل لإدارة حسابات العملاء، والديون، والمدفوعات، والحوالات الواردة، وكشوف الحسابات، والرسائل النصية التذكيرية، والنسخ الاحتياطي، واستيراد البيانات، مصمم بأحدث معايير واجهات المستخدم العربية (RTL) للعمل دون اتصال بالإنترنت (Offline 100%) على هواتف Android ومتصفحات الويب الحديثة.

## 🚀 المميزات والوظائف الرئيسية

### 1. لوحة التحكم والتحليل المالي (Dashboard)
- إجمالي الديون المحسوبة فعلياً من القيود المعتمدة.
- إجمالي المدفوعات والمبالغ المحصلة.
- صافي الرصيد المتبقي المستحق على العملاء.
- عدد العملاء الإجمالي، والعملاء المدينين، والمسددين بالكامل.
- أحدث العمليات المالية مع بيان كل عملية وتاريخها ورقمها المرجعي.
- أحدث الحوالات الواردة مع حالتها وتفاصيل المرسل وشركة التحويل.
- إمكانية تصفية العمليات حسب الفترة (اليوم، هذا الأسبوع، هذا الشهر، هذا العام، أو كافة الفترات).

### 2. إدارة العملاء والحسابات
- قائمة كاملة بالعملاء مع عرض رصيد كل عميل، إجمالي ديونه، وإجمالي مدفوعاته.
- بحث فوري بالاسم أو برقم الهاتف مع دعم الأرقام العربية والإنجليزية.
- تصفية العملاء (المدينون، المسددون، المؤرشفون، أو الكل).
- فرز العملاء (حسب الرصيد تنازلياً وتصاعدياً، أبجدياً، أو حسب تاريخ آخر عملية).
- كشف استباقي وتنبيه فوري عند تكرار رقم الهاتف لعميل آخر.
- **حماية السجل المحاسبي:** منع الحذف المباشر لأي عميل لديه حركات مالية للحفاظ على سلامة الدفاتر المحاسبية، مع إتاحة خيار "الأرشفة".

### 3. إدارة الديون والمدفوعات
- تسجيل الديون مع تحديد المبلغ، والتاريخ، ورقم الفاتورة/السند المرجعي، والبيان.
- تسجيل المدفوعات مع حماية تلقائية من السداد الزائد (منع تسجيل دفعة تفوق الرصيد المستحق افتراضياً لمنع الأرصدة السالبة).
- معالجة القيود الافتتاحية الموثقة (`opening`) والتسويات.
- حماية ضد الضغط المزدوج (Double-click lock) لمنع تكرار تسجيل العمليات بالخطأ.
- إمكانية إلغاء العمليات مع تسجيل سبب الإلغاء في سجل التدقيق المحاسبي دون حذف صامت.

### 4. كشوف الحسابات التفصيلية
- شاشة خاصة لكل عميل تتضمن بياناته، هاتفه، وملاحظاته.
- جدول كشف حساب زمني تصاعدي يوضح تاريخ كل عملية، نوعها، المدين، الدائن، والرصيد بعد كل عملية.
- طباعة كشف الحساب وتصديره بتنسيق طباعة نظيف (Print Stylesheet).
- تجهيز رسالة تذكير فورية للعميل مباشرة من كشف حسابه.

### 5. إدارة الرسائل النصية SMS
- كشف تلقائي بالعملاء المدينين فقط.
- إمكانية تحديد عميل واحد، عدة عملاء، أو تحديد جميع المدينين دفعة واحدة.
- محرك استبدال متغيرات القوالب التلقائي:
  - `{اسم_العميل}`
  - `{الرصيد}`
  - `{إجمالي_الديون}`
  - `{إجمالي_المدفوعات}`
  - `{التاريخ}`
- القالب الافتراضي:
  > مرحبًا {اسم_العميل}، نود تذكيرك بأن الرصيد المستحق عليك هو {الرصيد}. إجمالي الديون: {إجمالي_الديون}، وإجمالي المدفوعات: {إجمالي_المدفوعات}. التاريخ: {التاريخ}. شكرًا لك.
- إدارة القوالب: إضافة وتعديل وحذف القوالب المخصصة.
- معاينة الرسالة قبل فتح تطبيق الرسائل في الهاتف.
- فتح تطبيق الرسائل عبر جسر Android الأصلي أو رابط `sms:` مع خضوع كل رسالة لموافقة المستخدم (تطبيقاً لسياسات الخصوصية والأمان ومنع الإرسال التلقائي في الخلفية).
- حفظ سجل تاريخي للرسائل المجهزة والمرسلة مع إمكانية مسحه.

### 6. إدارة الحوالات الواردة ومنع التكرار
- دعم شركات الصرافة والتحويل المعتمدة:
  1. النجم
  2. الامتياز إكسبرس
  3. داديه
  4. الأكوع موني
  5. إتش بي
  6. شركة أخرى
- كشف ذكي وتلقائي لمنع تكرار تسجيل الحوالة ذاتها بالاعتماد على اسم الشركة والرقم المرجعي (معالجة نصية دقيقة تمنع الخلط بين الرقم المرجعي والمبلغ المالي).
- ربط الحوالة بالعميل المستحق.
- تأكيد الحوالة وترحيلها كدفعة مسددة لحساب العميل بنقرة واحدة، مع قفل برمجي يمنع تكرار الترحيل مهما ضغط المستخدم.

### 7. التقارير المالية المتنوعة
- تقرير إجمالي الديون والمدفوعات.
- تقرير الأرصدة المتبقية لكافة العملاء.
- تقرير العملاء المدينين والمسددين.
- تقرير حركة العمليات المالية خلال فترة زمنية محددة.
- تقرير الحوالات الواردة وحالات ترحيلها.
- تصدير فوري إلى ملفات CSV تدعم اللغة العربية وترميز UTF-8 مع BOM لقراءتها في Microsoft Excel دون تشويه الحروف.
- تصدير وطباعة تقارير مالية جاهزة.

### 8. النسخ الاحتياطي والاستعادة الآمنة
- تصدير نسخة احتياطية كاملة بصيغة JSON باسم `SmartDebtManager-backup-*.json`.
- فحص بنية الملف، إصدار التنسيق، وتكامل العلاقات المعرفية بين العملاء والعمليات والحوالات قبل الاستعادة.
- **نسخة أمان تلقائية:** أخذ لقطة أمان فورية من البيانات الحالية قبل تنفيذ أي استعادة، مع التراجع التلقائي في حال وجود أي خطأ.
- خياران للاستعادة:
  1. **استعادة كاملة:** استبدال البيانات بعد موافقة المستخدم.
  2. **استيراد ودمج:** إضافة السجلات الجديدة فقط مع استبعاد التكرارات.

### 9. استيراد ملفات CSV
- معالجة ملفات CSV العربية وترميز UTF-8.
- التعرف التلقائي على أعمدة الأسماء، الهواتف، والأرصدة والملاحظات.
- تحويل الأرصدة المستوردة إلى قيود افتتاحية موثقة ومعتمدة.
- نافذة معاينة تظهر عدد الصفوف الكلي، السجلات الصالحة، غير الصالحة، والعملاء المكررين قبل الحفظ.

### 10. المساعد الذكي المحلي (Smart Local Assistant)
- تحليل محلي صارم قائم على القواعد البرمجية (Rule-based).
- كشف أرقام الهواتف المكررة بين أكثر من عميل.
- كشف أرقام الهواتف غير الصالحة.
- ترتيب كبار المدينين وحجم ديونهم واقتراح تذكيرات سداد.
- كشف الأرصدة الشاذة أو الدائنة لمراجعتها.
- احتساب معدل كفاءة التحصيل المالي (Collection Rate %).

### 11. الخصوصية والأمان
- تخزين البيانات محلياً على جهاز المستخدم (Offline Local Storage).
- عدم استخدام خوادم خارجية أو خدمات تتبع تتلقى بيانات العملاء.
- عدم طلب أي صلاحيات حساسة أو غير ضرورية في نظام Android.

يمكنك تشغيل حزمة الاختبارات المحاسبية والتخزينية مباشرة من داخل التطبيق:
1. افتح شريط الأقسام السريع واضغط على **"فحص النظام"**.
2. اضغط على زر **"تشغيل حزمة الاختبارات المحاسبية الآن"**.
3. ستظهر نتائج كافة حالات الاختبار العشر (بما فيها حالات التسديد الكامل، محاولة السداد على رصيد صفري، منع تكرار الحوالات، استيراد الأرصدة الافتتاحية، وأمان النسخ الاحتياطي) بحالة **PASS**.


## 13. محرك الاستيراد الهجين الذكي (Hybrid SQLite Import Engine)

تم تطوير مسار SQLite الأصلي داخل Android ليقرأ قاعدة البيانات بوضع القراءة فقط، ويفحص `sqlite_master` و`PRAGMA table_info` و`foreign_key_list` و`index_list` و`index_info`، ويقرأ الصفوف ضمن حدود حماية واضحة، ثم ينفذ `quick_check` و`foreign_key_check`.

- اكتشاف الجداول والأعمدة والمفاتيح والعلاقات والفهارس بدل البحث عن أسماء ثابتة فقط.
- مطابقة أعمدة عربية وإنجليزية بالمرادفات، مع الاستفادة من المفاتيح الخارجية.
- حساب الأرصدة من الحركات ذات الاتجاه المعروف فقط؛ لا يتم تحويل الحركة الغامضة إلى دين أو دفعة بالتخمين.
- عرض تقرير المطابقات للمستخدم وطلب الموافقة قبل الترحيل.
- منع الاستيراد عند بتر البيانات أو فشل سلامة SQLite أو وجود مخالفات مفاتيح خارجية.
- إنشاء بصمة SHA-256 للمصدر لمنع تكرار الحركات الأصلية عند إعادة استيراد الملف نفسه.
- المحافظة على Adapter الخاص بقاعدة Market DB السابقة.

تفاصيل التنفيذ والحدود الحالية في `docs/HYBRID_IMPORT_ENGINE_AR.md`.

## 14. الاختبارات والبناء

تشغيل اختبارات المحاسبة والاستيراد:

```bash
node run_tests.js
```

آخر نتيجة اختبار مسجلة في هذه الحزمة: **21/21 ناجح**، بما فيها اختبار مخطط SQLite عام واختبار منع تكرار الحركات.

بناء APK:

```bash
./gradlew --no-daemon clean :app:assembleDebug
```

تم تضمين Workflow في `.github/workflows/android-build.yml` لتشغيل الاختبارات وبناء APK تلقائيًا على GitHub Actions.

معرف التطبيق الحالي محفوظ للتوافق مع المشروع الأصلي: `com.smartdebt.app`.
