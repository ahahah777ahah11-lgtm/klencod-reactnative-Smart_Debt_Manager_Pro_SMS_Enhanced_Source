=====================================================================
مدير الديون الذكي برو SMS - Smart Debt Manager Pro SMS
حزمة تحويل الويب إلى تطبيق (WebToApp / HTML to APK Builder Package)
=====================================================================

أهلاً بك! هذه الحزمة مجهزة ومحسنة خصيصاً للعمل كتطبيق أندرويد رسمي مستقل 100% بدون إنترنت (Offline-First).

المميزات الرئيسية المدمجة:
1. ملف index.html مدمج وشامل (All-In-One Bundle):
   - كافة تنسيقات CSS والتدرجات اللونية الزرقاء والأزرار الاحترافية مدمجة بالكامل داخله.
   - كافة محركات المحاسبة والرسوم البيانية (Pie Chart) وتنبيهات التقويم مضمنة داخله بدون أي اتصال خارجي.
   - لن تختفي التنسيقات أو تظهر الأزرار الافتراضية حتى لو كان التطبيق في وضع الطيران (Airplane Mode).

2. الميزات المالية الجديدة المضافة:
   - نظام الدفعات الجزئية (Partial Payments) وربطها بديون محددة مع حساب المتبقي لكل دين.
   - رسم بياني دائري تفاعلي (Pie Chart) في شاشة التقارير يوضح توزيع المستحقات حسب الفئة (عادي، VIP، متعثر).
   - استيراد ملفات Excel و قواعد البيانات (DB/SQLite) وكشوف حسابات PDF مع دعم الترميز العربي UTF-8 BOM.
   - جدولة التنبيهات في تقويم الهاتف لمواعيد الاستحقاق.

طريقة التثبيت عبر WebToApp أو HTML to APK Builder:
--------------------------------------------------
الخيار الأول (الأسهل والأسرع):
- افتح تطبيق WebToApp أو HTML to APK Builder.
- اختر "Local HTML File" أو "Upload HTML".
- حدد ملف `index.html` الموجود مباشرة في هذه الحزمة.
- سيعمل التطبيق بكامل التنسيقات والرسوم البيانية والأزرار والخطوط وبأعلى أداء!

الخيار الثاني (رفع ملف مضغوط ZIP):
- اختر "Upload ZIP File" ثم حدد `html-to-apk-package.zip`.
- اضبط صفحة البداية على `index.html`.

تثبيت الـ APK الجاهز مباشرة:
---------------------------
إذا كنت تريد التثبيت الفوري دون استخدام WebToApp، يمكنك تثبيت ملف APK الجاهز والمبني مباشرة:
`SmartDebtManagerProSMS.apk`
حيث يحتوي على الويب فيو الأصلي المضبوط لحماية الخطوط ومنع تشوه الأحجام على شاشات سامسونج والأجهزة الذكية.

نتمنى لك تجربة محاسبية ممتازة وآمنة لحساباتك وعملائك!
